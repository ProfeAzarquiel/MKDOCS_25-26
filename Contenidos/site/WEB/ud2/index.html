    INTRODUCCIÓN Y CONCEPTOS BÁSICOS

    CSS es el acrónimo de Cascading Style Sheets (Hojas de Estilo en Cascada), y es un lenguaje que permite definir la apariencia de los elementos HTML en una página web.

    Es decir, mientras que HTML define la estructura y el contenido (lo qué hay en la página), CSS define cómo se distribuyen (donde y como se colocan) y como se ven esos elementos.

    De modo que CSS nos permite controlar los aspectos de diseño web como los colores, las tipografías, los márgenes y otros más relacionados con la maquetación web; en hojas de estilos, separando el contenido de su presentación.

    COMO AÑADIR HOJAS DE ESTILO A NUESTRO HTML

    Para enlazar un fichero HTML con su hoja de estilos, debemos insertar en la cabecera HTML (head) una línea similar a la que veremos a continuación, especificando entre otras cosas la ruta donde se encuentra dicha hoja:

    <link href="css/misestilos.css" rel="stylesheet" type="text/css" />

    MODELO DE CAJAS

    Es el modelo que usa CSS, y que se basa en tratar todos los elementos que se representan en una página web como cajas con una serie de características que las definen.

    Como vemos en la imagen anterior, cada caja esta compuesta por:

    • Contenido (content): es el elemento que queremos mostrar.
    • Padding (padding): separación entre el contenido y el borde.
    • Borde (border): linea que delimita la caja, puede ser visible o no.
    • Margen (margin): es la separación entre una caja y sus adyacentes.

    Por otro lado, una caja puede comportarse principalmente de dos formas:

    • Como elemento en línea (inline): Cada caja que introducimos se coloca al lado de la otra en la misma línea; cuando no caben más, salta a la siguiente línea. Por ejemplo: <img>, <a>, <label>... se comportan por defecto como elemento en línea.
    • Como elemento en bloque (block): Cada caja que introducimos se coloca en una nueva línea. Por ejemplo: <h1>, <p>, <h2>... se comportan por defecto como bloques.

    ESTILOS EN CASCADA

    CSS, como su propio nombre indica, funciona en cascada, es decir, los estilos se propagan hacia abajo.

    Del mismo modo, si dos o más reglas entran en conflicto o se solapan, prevalecerá la regla que se aplica en el elemento más específico, es decir, el elemento más abajo en el árbol DOM.

    Árbol DOM: Es una representación jerárquica de un documento HTML, donde el nodo raíz es <html> y cada etiqueta se convierte en un nodo.

    SELECTORES CSS

    Los selectores son códigos o patrones que sirven para indicar sobre qué elementos se aplicará un conjunto de reglas de estilo. A continuación, vemos las diferentes posibilidades que tenemos para filtrar los elementos de un sitio web:

    TIPO EJEMPLO EXPLICACIÓN
    Selector universal * Se aplica a todos los elementos de la página.
    Etiqueta img Selecciona todos los elementos del tipo <img>.
    ID #contenedor Selecciona el único elemento cuyo Id sea contenedor.
    Clase .parrafo Selecciona todos los elementos pertenecientes a la clase parrafo.
    Varias etiquetas h1, h2, h3 Selecciona todos los elementos h1, h2 y h3.
    Etiqueta hija (descendiente) section img Selecciona todas las imágenes que estén dentro de una sección.
    Etiqueta hija DIRECTA p > img Se usa el símbolo mayor que
    Por atributos img[alt="primero"] Para seleccionar una etiqueta por uno de sus atributos
    Hermano adyacente h1 + h2 Para seleccionar una etiqueta que va justo después de otra
    Hermano general p ~ img Para seleccionar una etiqueta que va después (sin importar si es inmediatamente consecutiva)

    USO AVANZADO DE LOS SELECTORES

    Además de los tipos de selectores comunes que hemos visto, podemos personalizar aún más sobre que cosa aplicamos una serie de estilos, pudiendo aplicar estilos a partes específicas de un elemento o a elementos basándose en su estado, posición o interacción.

    Para conseguirlo, existen una serie de palabras claves diferenciadas en dos grandes grupos: pseudo-clases y pseudo-elementos.

    PSEUDO-CLASES

    Seleccionan elementos que se encuentran en un estado específico o en una posición concreta dentro del árbol DOM, sin necesidad de añadir clases adicionales en nuestro código HTML.

    Se indican a continuación del selector y separadas por dos puntos ":". Por ejemplo:

    selector:pseudo-clase

    Podemos consultar el listado completo de pseudo-clases en el apartado Pseudo-classes de Mozilla Developer Network (MDN).

    PSEUDO-ELEMENTOS

    Los pseudoelementos permiten aplicar estilos a partes específicas o contenido generado de un elemento HTML.

    El uso es similar que las pseudoclases, pero en este caso van separados del selector por dobles dos puntos "::". Por ejemplo:

    selector::pseudo-elemento

    Se puede consultar el listado completo de pseudo-elementos en el apartado Pseudo-elements de Mozilla Developer Network (MDN).

    PROPIEDADES CSS

    Una vez que hemos visto como podemos filtrar o seleccionar las partes o elemntos de nuestra web sobre los que queremos aplicar ciertos estilos, ahora nos queda definir propiamente esos estilos.

    Para ello haremos uso de las propiedades CSS, que no son más que los diferentes parámetros que podemos usar una declaración CSS para definir el aspecto, comportamiento y distribución de los elementos seleccionados. Su sintáxis de uso es la siguiente:

    selector {
  propiedad: valor;
}

    A través de ellas podemos personalizar el color, tamaño, fondo, tipo de letra, posicionamiento, opacidad o espaciado; entre muchísimas otras cosas. El listado de propiedades es muy extenso y se puede consultar en el apartado CSS Properties de Mozilla Developer Network (MDN).

    PROPIEDAD DISPLAY

    • inline: No rompen el flujo de la línea y se van colocando uno detrás de otro mientras caben. Ignoran width y height.
    • inline-block: Como inline, pero sí podemos asignarles width y height.
    • block: Rompen el flujo de línea provocando un salto de línea anterior y posterior. Por defecto ocupan todo el ancho de la etiqueta padre.
    • none: El elemento desaparece sin dejar hueco vacío en su lugar.

    Relacionados con tablas

    Se comportan como el elemento de tabla indicado:

    • table
    • table-row
    • table-cell
    • table-caption
    • table-column
    • table-colgroup
    • table-header-group
    • table-footer-group
    • table-row-group

    ℹ Valores flex y grid: (Próxima unidad)

    LAYOUTS

    • Fixed: Establece un tamaño fijo en píxeles para la anchura de los elementos. Permite control total del tamaño, pero en pantallas pequeñas muestra scroll horizontal y en grandes deja muchos espacios en blanco en los márgenes.
    • Elastic: Establece la anchura de los elementos en em (tamaño de letra por defecto). Al usar el zoom, los elementos se escalan con el texto, pero según cuánto escalemos pueden llegar a solaparse.
    • Fluid: Establece el ancho de los elementos en % (con respecto al padre). Los elementos mantienen sus proporciones independientemente de la pantalla, pero en pantallas pequeñas se pueden generar columnas muy estrechas y alargadas.
    • Híbrido: Establece el ancho máximo y mínimo que podrán crecer o encoger los elementos en píxeles (max-width y min-width). Estos atributos suelen aplicarse combinados con los principios de alguno de los layouts anteriores.
    • Responsive: El layout va cambiando dependiendo generalmente de la anchura de la pantalla. Si uso más de un layout para la página, se denomina adaptive.

    BOX-SIZING

    Dimensiones por defecto de la caja de un elemento

    • Altura del elemento = $\text{altura del contenido} + \text{padding} + \text{borde}$
    • Anchura del elemento = $\text{anchura del contenido} + \text{padding} + \text{borde}$

    Para no tener que calcular constantemente esto, se añade el siguiente código CSS indicando la propiedad border-box:

    * {
  -webkit-box-sizing: border-box;
  -moz-box-sizing: border-box;
  box-sizing: border-box;
}

    Tipos de box-sizing

    • border-box: El tamaño que demos al elemento será la dimensión total de la caja.
    • content-box: Funcionamiento por defecto (habría que realizar la suma explicada arriba).
    • padding-box: Solo se suma el tamaño del borde y el contenido para calcular las dimensiones de la caja.

    CENTRADO

    Centrado Horizontal

    • Elementos en línea: Aplicar la propiedad text-align: center al contenedor padre.
    • Elementos en bloque:
    • Un elemento: Especificar anchura del elemento a centrar y usar la propiedad margin: Xpx auto.
    • Varios elementos: Aplicar text-align: center al contenedor y display: inline-block en los elementos a centrar.
    • Contenedores flex: (Próxima unidad)

    Centrado Vertical

    • Elementos en línea: Indicando el mismo padding arriba y abajo, o bien simulando un elemento tabla con display e indicando la propiedad vertical-align: middle (en este caso el padre debe tener altura fija).
    • Elementos en bloque: Usando la propiedad position en el contenedor (padre) y en el elemento.

    Si conocemos la altura:

    .contenedor {
  position: relative;
}

.elemento_a_centrar {
  height: 100px;
  margin-top: -50px; /* mitad de la altura */
  position: absolute;
  top: 50%;
}

    Si no conocemos la altura:

    .contenedor {
  position: relative;
}

.elemento_a_centrar {
  position: absolute;
  top: 50%;
  transform: translateY(-50%);
}
    • Contenedores flex: (Próxima unidad)

    POSITION

    Permite romper el flujo normal de los elementos (en línea o en bloque) y colocarlos en lugares específicos. Sus valores pueden ser:

    • static: Valor por defecto. El elemento sigue el flujo correspondiente y no atiende a top, bottom, left, right o z-index.
    • relative: Como static, pero sí atiende a los desplazamientos expresados en top, bottom, left, right o z-index.
    • fixed: Se posiciona en relación al documento. Su posición permanece fija independientemente del scroll.
    • absolute: Se comporta como fixed, pero en relación con la primera etiqueta padre que tenga position: relative.
    • sticky: Se comporta como relative hasta llegar a una posición de scroll específica, a partir de la cual actúa como fixed.

    💡 Propiedad z-index: Sirve para establecer el orden de superposición cuando los elementos se solapan. Funciona como capas: el elemento con un z-index más alto se posicionará por delante.

    COLUMNAS

    Podemos dividir el contenido en varias columnas mediante las siguientes propiedades:

    • column-count: Especifica el número de columnas que tendrá el elemento contenedor.
    • column-width: Fijar el ancho de las columnas del contenedor.
    • column-gap: Establece la distancia entre columnas.
    • column-rule: Similar a border, permite especificar el estilo, color y anchura de la línea divisoria.
    • column-span: Valores all o none para indicar si un elemento hijo rompe el flujo en columnas o no.
    • column-fill: El contenedor debe tener altura; establece cómo se rellenan las columnas (auto o balance).
    • break-inside: Con valor avoid (o void) para evitar que un elemento se rompa entre dos columnas.

    ELEMENTOS FLOTANTES

    • float: Creada originalmente para disponer texto alrededor de una imagen. Hoy se utiliza para maquetación flotando elementos y ajustando sus dimensiones. Valores: left o right.
    • clear: Fuerza a un elemento a dejar de flotar. Valores: left, right o both.
    • clearfix hack: Si un contenedor solo contiene elementos flotantes, su altura pasa a ser cero por defecto (al flotar, el padre pierde la referencia de altura de sus hijos). Para solucionarlo, se asigna la clase clearfix al contenedor:
    /* Opción 1 */
.clearfix {
  overflow-y: auto;
}

/* Opción 2 */
.clearfix::after {
  content: "";
  clear: both;
  display: table;
}

    MAQUETACIÓN CON FLEX y GRID

    ¿QUÉ SON FLEX Y GRID?

    Son dos valores para la propiedad display añadidos a CSS3 / HTML5 que permiten maquetar webs de forma más sencilla y eficiente que con los métodos tradicionales.

    • Flexbox (display: flex): Trabaja en una sola dimensión (horizontal o vertical). Permite alinear, escalar y distribuir el espacio restante de sus elementos hijos.
    • Grid (display: grid): Es el sistema de maquetación bidimensional más potente, ya que permite trabajar de forma simultánea en filas y columnas.

    MAQUETACIÓN CON FLEX

    Al maquetar con Flex existen dos componentes principales: el contenedor Flex (etiqueta padre) y los elementos flexibles (hijos directos).

    Las propiedades modificables de los elementos flexibles incluyen:

    • Altura y anchura
    • Orden
    • Alineación (horizontal o vertical)
    • Distribución a lo largo del contenedor padre

    PROPIEDADES DEL CONTENEDOR FLEX

    Al asignar display: flex a un contenedor padre, este organiza automáticamente los elementos hijo en forma de fila (row por defecto), en el orden del documento HTML.

    • flex-direction: Modifica la dirección de los elementos.
    • row (por defecto)
    • row-reverse
    • column
    • column-reverse
    • flex-wrap: Controla cómo se ajustan los elementos al tamaño del padre cuando no caben en una sola línea.
    • nowrap (por defecto, no envuelve los elementos)
    • wrap (dispone los elementos en varias líneas de arriba abajo)
    • wrap-reverse (dispone los elementos en varias líneas de abajo arriba)
    • flex-flow: Propiedad abreviada (shorthand) para combinar dirección y ajuste.
    • Ejemplo: flex-flow: row-reverse wrap;
    Alineación y Distribución Horizontal

    La propiedad justify-content controla la alineación a lo largo del eje principal (main axis):

    • flex-start (por defecto): Alinea los elementos al principio.
    • flex-end: Alinea los elementos al final.
    • center: Centra los elementos en el contenedor.
    • space-between: Distribuye el espacio libre equitativamente entre los elementos (los extremos pegados al borde).
    • space-around: Distribuye el espacio equitativamente, reservando la mitad del espacio en los extremos.
    • space-evenly: Distribuye el espacio exactamente igual entre elementos y extremos.
    Alineación Vertical

    La propiedad align-items controla la alineación en el eje transversal (cross axis):

    • flex-start: Alinea arriba.
    • flex-end: Alinea abajo.
    • center: Centra verticalmente.
    • stretch (por defecto si no se indica altura): Estira los elementos para ocupar toda la altura del padre.
    • baseline: Alinea las líneas base del texto contenido en los elementos.

    Para personalizar la alineación cuando hay múltiples líneas de elementos hijos, se utiliza align-content (acepta valores como flex-start, flex-end, center, stretch, space-between, space-around).

    PROPIEDADES DE LOS ELEMENTOS FLEXIBLES

    Orden
    • order: (por defecto 0) Permite cambiar el orden visual de aparición de un elemento hijo sin modificar el HTML.
    • Ejemplo: order: 3;
    Tamaño y Crecimiento
    • flex-grow: (por defecto 0) Factor de crecimiento para repartir el espacio disponible sobrante.
    • Ejemplo: flex-grow: 2;
    • flex-shrink: (por defecto 1) Factor de contracción cuando no hay suficiente espacio en el contenedor.
    • Ejemplo: flex-shrink: 3;
    • flex-basis: (por defecto auto) Tamaño inicial base del elemento antes de repartir el espacio restante.
    • Ejemplo: flex-basis: 20%;
    • flex: Abreviatura que engloba flex-grow, flex-shrink y flex-basis.
    • Ejemplo: flex: 1 1 20%;
    Alineación Individual con Flex
    • align-self: Permite sobrescribir la propiedad align-items del contenedor para un elemento individual. Acepta los mismos valores (flex-start, flex-end, center, stretch, baseline).
    • Ejemplo: align-self: flex-end;

    MAQUETACIÓN CON GRID

    Grid utiliza un contenedor padre con la propiedad display: grid para controlar una estructura en rejilla compuesta por filas y columnas.

    PROPIEDADES DEL CONTENEDOR GRID

    Estructura de Filas y Columnas
    • grid-template-columns: Define el número, tamaño y nombre de las columnas.
    • grid-template-columns: 20% 50% 30%;
    • grid-template-columns: [id] 50px [producto] auto;
    • grid-template-rows: Define el número, tamaño y nombre de las filas.
    • grid-template-rows: 100px auto 100px auto;
    • grid-template-rows: [uno] 20px [dos] 40px [tres] auto;
    • grid-row-gap / grid-column-gap (o gap): Separación entre filas y columnas.
    • repeat(): Función para replicar dimensiones o patrones.
    • Ejemplo: grid-template-columns: repeat(3, [mi-columna] 20%) auto;
    • Unidad fr: Fracción del espacio disponible para reparto por pesos.
    • Ejemplo: grid-template-columns: 2fr 100px 1fr 2fr;
    Alineación Interna de Celdas
    • justify-items (Horizontal): Alinea los elementos dentro de sus respectivas celdas.
    • start | end | center | stretch (por defecto)
    • align-items (Vertical): Alinea los elementos verticalmente dentro de su celda.
    • start | end | center | stretch
    • place-items: Abreviatura para alineación vertical y horizontal (place-items: <align-items> <justify-items>).
    • Ejemplo: place-items: start center;
    Distribución del GRID en el Contenedor

    Si la rejilla es más pequeña que el contenedor padre:

    • justify-content (Horizontal): start | end | center | stretch | space-between | space-around | space-evenly
    • align-content (Vertical): Mismos valores que en la distribución horizontal.
    • place-content: Abreviatura para ambos ejes.
    • Ejemplo: place-content: center space-around;
    Colocación Implícita

    Define el comportamiento de elementos colocados fuera de la rejilla definida:

    • grid-auto-columns: Ancho por defecto de columnas implícitas.
    • grid-auto-rows: Alto por defecto de filas implícitas.
    • grid-auto-flow: Controla la dirección del flujo automático de colocación.
    • row (por defecto, llena filas primero)
    • column (llena columnas primero)
    • dense (intenta rellenar los huecos anteriores; usar con precaución)

    PROPIEDADES DE LOS ELEMENTOS DENTRO DE UN GRID

    Nota: A los elementos dentro de un contenedor Grid NO les afectan las propiedades float, display: inline-block, display: table-cell, vertical-align ni las propiedades de columnas múltiples (column-*).

    Área Ocupada

    Para indicar las líneas de la rejilla donde empieza y termina un elemento, se usan las propiedades:

    • grid-row-start
    • grid-column-start
    • grid-row-end
    • grid-column-end

    Aunque se pueden definir filas o columnas en una única linea, usando la sintaxis abreviada como se muestra a continuación:

    • grid-column: < start > / < end >;
    • grid-row: < start > / < end >;

    Y todas ellas, pueden definirse en una única linea, bajo la propiedad grid-area.

    • grid-area: < row-start > / < column-start > / < row-end > / < column-end >;

    Ejemplos de uso:

    /* Elemento hijo que empiece en el separador de columna 2 y se extienda 3 columnas más */
grid-column-start: 2;
grid-column-end: span 3;

/* Elemento hijo que empiece en la fila 1 y columna 1; y termine en la fila 2 y columna 5*/
grid-area: 1 / 1 / 2 / 5
    Alineación Individual con Grid
    • justify-self: Alineación horizontal del elemento dentro de su celda (start, end, center, stretch).
    • align-self: Alineación vertical del elemento dentro de su celda (start, end, center, stretch).

    DEFINICIÓN DE ÁREAS EN GRID

    Tambien tenemos otra opción, en lugar de calcular las líneas de la rejilla. Y es que podemos nombrar áreas dentro de los elementos hijos con grid-area y distribuirlas visualmente en el contenedor padre usando grid-template-areas, como vemos a continuación:

    Ejemplo de Configuración de Áreas

    .container {
  display: grid;
  grid-template-columns: repeat(5, 20%);
  grid-template-rows: repeat(3, 100px);
  grid-template-areas:
    "cab  cab  cab  cab  cab"
    "menu .    main main main"
    "menu pie  pie  pie  pie";
}

/* Asignación a los elementos hijos */
.header { grid-area: cab; }
.sidebar { grid-area: menu; }
.main-content { grid-area: main; }
.footer { grid-area: pie; }

    Nota: El punto (.) en grid-template-areas representa un espacio o hueco vacío dentro de la rejilla.

    Es posible resumir la configuración completa en propiedades compuestas como grid-template o grid, aunque generalmente no se recomienda porque dificulta la lectura del código.

    MAQUETACIÓN RESPONSIVA

    ¿QUÉ ES EL DISEÑO RESPONSIVO?

    Curso Gratuito de Google

    Muy recomendable este curso que explora todos los aspectos del diseño web responsivo actual, donde aprenderás a crear sitios que, además de verse bien, también funcionen correctamente en todo tipo de dispositivos.

    Google Developers

    Es la característica del diseño web que permite que una página se muestre correctamente en una variedad de dispositivos y tamaños de pantalla, adaptando su maquetación (layout) al entorno de visualización.

    A grandes rasgos, esto se consigue mediante la combinación de HTML + CSS + Media Queries. Su funcionamiento se basa en realizar consultas sobre las características de la pantalla (como ancho o alto) y aplicar reglas CSS específicas según sus valores.

    Además de eso, podemos aplicar una serie de características sobre diferentes elementos de nuestra web, como textos e imágenes, para que se adapten y rendericen mejor según el dispositivo utilizado.

    ELEMENTOS RESPONSIVOS

    VIEWPORT

    Es el área de la pantalla donde el navegador renderiza el contenido, es decir, el espacio disponible para mostrar el sitio web.

    En ordenadores de escritorio coincide con la ventana del navegador, pero en dispositivos móviles no es así. Por ello, se diferencian dos tipos:

    • Layout Viewport: Es la dimensión que se tiene en cuenta para la aplicación de los estilos CSS.
    • Visual Viewport: Es la parte de la página que el usuario realmente ve en pantalla en un momento dado.

    Para garantizar que una web se escale correctamente en móviles, es imprescindible incluir la siguiente etiqueta meta en el <head> del HTML:

    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    LAYOUT

    Se refiere a la disposición y comportamiento de los elementos dentro de la estructura de nuestro sitio web.

    En la maquetación tradicional, el layout se estructuraba usando diferentes formas para expresar las dimensiones de los elementos:

    • ⚠️ Fixed (Píxeles): Control total sobre las dimensiones, pero suele generar scroll horizontal en pantallas pequeñas si no se escala.
    • ⚠️ Elastic (em): Permite escalar con el zoom manteniendo proporciones, pero no se adapta automáticamente al cambiar el tamaño de pantalla.
    • ✅ Fluid (%): Al expresarse en porcentajes, los elementos se adaptan dinámicamente al viewport. Es el tipo de layout utilizado para conseguir un diseño más responsivo.

    Sin embargo, hoy en día, tras la llegada de Flexbox y Grid, todo lo anterior cayó casi en desuso, ya que con ellos, los elementos crecen y encogen dinámicamente hasta rellenar el espacio disponible, eliminando la decesidad de calcular porcentajes específicos.

    PATRONES RESPONSIVOS

    PATRÓN FUNCIONAMIENTO EJEMPLO
    TINIY TWEAKS Es el patrón más simple y sencillo de implementar de todos. Se basa en una sóla columna para el contenido. Sus cambios son básicamente que dependiendo del tamaño de pantalla, se amplían los espaciados y el tamaño de fuente. Suele utilizarse en sitios con mucho contenido escrito, para mejorar la experiencia de lectura.
    COLUMN DROP Este patrón consiste en que cada bloque de contenido, que en un smartphone veremos en filas y columna única; vaya formando nuevas columnas según va creaciendo el tamaño de pantalla. De modo que en cada breakpoint el bloque de la siguiente fila, pasa a formar una nueva columna.
    MOSTLY FLUID Consiste en configurar un Grid de tamaño flexible, de modo que según va creciendo la pantalla, los distintos bloques se agrupan ocupando toda el espacio disponible. Cuando estamos en un smartphone todo forma una única columna, quedando los elementos colocados hacía abajo en varias filas. En pantallas más grandes el diseño no cambia, es el mismo pero termina quedando centrado en la pantalla con un tamaño de ancho fijo.
    LAYOUT SHIFTER Este es uno de los patrones más complejos (también el más adaptativo). Ya que consiste en mover los bloques de contenido cambiando totalmente el Layout, con cada breakpoint.
    OFF CANVAS Es uno de los más utilizados para aplicaciones moviles y consiste en ocultar contenido en la pantalla (generalmente menús o navegación) y únicamente es visible si realizamos un determinado gesto. Cuando la pantalla es más ancha, este contenido vuelve a hacerse visible.

    En el artículo Los 5 patrones del Responsive Design - Carlos Azaustre, podeís encontrar ejemplos de implementación de cada uno de estos patrones.

    MEDIA QUERIES

    Son el componente clave del diseño responsivo, ya que nos permiten aplicar estilos de forma condicional, dependiendo del tipo dispositivo (como print o screen) o de ciertas características de esten como la resolución de la pantalla (aspect-ratio) o el ancho del viewport (min-width) del navegador.

    La forma de utilizar media queries es mediante "reglas-at" (At-Rules), que son declaraciones CSS que comienzan con el símbolo "@", seguido de un identificador. Para este caso concreto se usan las reglas @media e @import.

    En general, una media query se compone del tipo de medio opcional y cualquier cantidad de expresiones de características de medios, que pueden combinarse opcionalmente de varias maneras usando operadores lógicos (or, and, not, only).

    RECUERDA...

    Si queremos aplicar la filosofía Mobile First (tal y como se sugiere más arriba), controlaremos el ancho del viewport exclusivamente con min-width. Ya que diseñaremos nuestro layout movil en primer lugar y a partir de ahí iremos aumentando el tamaño de pantalla.

    En cuanto a los tipos de medios, podemos usar all, print y screen; asumiendo que es all, cuando no se indica nada. Y sobre las características de medios posibles, hay una amplia lista que podemos ver en MDN Web - Media feature; sin embargo, la que vamos a utilizar, como mínimo, para conseguir que nuestros diseños sean responsivos, será la opción width, que nos permite aplicar estilos basados en el ancho del viewport.

    Para ello, se suelen establecer una serie de tamaños o breakpoints, que son los puntos de corte o anchos de pantalla, donde queremos que se produzca un cambio en el layout. Hay multitud de ejemplos de breakpoints típicos publicados, como los que usan las grandes compañias como Twitter (ahora X) o Bootstrap; pero dos de los más comunes son 768px (a partir del cual podemos tener 2 columnas comodas) y 1024px (a partir del cual se puede trabajar con 3 columnas).

    Algunos ejemplos de media queries podriamos usar son:

    /* Se aplica a dispositivos con ancho de viewport sea igual o mayor a 768px */
@media (min-width: 768px) {
  /* Estilos a aplicar */
}

/* Se aplica exclusivamente a dispositivos con pantalla y cuyo viewport tenga 50em o más de ancho */
@media only screen and (min-width: 50em) {
  /* Estilos a aplicar */
}
/* Se aplica a dispositivos con ancho de viewport de 600px o superior y orientación apaisada*/
@media (min-width: 600px) and (orientation: landscape) {
  /* Estilos a aplicar */
}

/* Se aplica a dispositivos con ancho de viewport de 30em o superior*/
@media (width >= 30em)  {
  /* Estilos a aplicar */
}

    También, si así lo quisieramos, podemos aplicar diferentes hojas de estilos sobre el mismo HTML, para cada uno de los breakpoints que hayamos definido, como vemos en el siguiente ejemplo:

    <!-- Para pantallas de hasta 576px de ancho -->
<link rel="stylesheet" media="(max-width: 576px)" href="small.css" />

<!-- Para pantallas de hasta 768px de ancho -->
<link rel="stylesheet" media="(max-width: 768px)" href="medium.css" />

<!-- Para pantallas de hasta 992px de ancho -->
<link rel="stylesheet" media="(max-width: 992px)" href="large.css" />

    IMÁGENES RESPONSIVAS

    Para optimizar el uso de imágenes responsivas se busca reducir el consumo de ancho de banda y servir la resolución adecuada según la pantalla. Para conseguirlo podemos usar las siguientes características:

    Propiedades CSS clave:

    PROPIEDAD OBJETIVO
    max-width: 100% + height: auto La regla básica fundamental. Escala la imagen proporcionalmente hacia abajo para que nunca desborde su contenedor padre, sin distorsionar sus proporciones.
    object-fit Controla cómo se adapta una imagen a un contenedor con dimensiones fijas: cover Rellena todo el espacio sin deformar la imagen y corta los bordes sobrantes (ideal para cards o galerías); contain Ajusta la imagen completa dentro del contenedor sin recortarla.
    object-position Define el punto de anclaje cuando usamos object-fit: cover. Por ejemplo, object-position: top center para no recortar las caras en un retrato.
    aspect-ratio Permite reservar el espacio de aspecto adecuado (por ejemplo, aspect-ratio: 16 / 9) antes de que cargue la imagen, evitando saltos bruscos en el diseño.

    Atributos HTML para carga eficiente:

    Aunque con el CSS anterior controlamos la presentación visual, es el código HTML quien se encarga de optimizar el tiempo de carga y la eficiencia a la hora de renderizar imágenes:

    PROPIEDAD OBJETIVO
    srcset y sizes Permiten ofrecer varios archivos con distintas resoluciones en base a la densidad de píxeles y el tamaño del viewport, para descargar únicamente el archivo idóneo en cada caso.
    Etiqueta <picture> Se usa cuando queremos hacer un "art direction", como mostrar una imagen recortada en vertical para móviles y una horizontal en ordenadores; o también para servir formatos modernos (WebP / AVIF) con fallback a JPEG.
    loading="lazy" Atributo nativo en HTML que evita cargar imágenes que el usuario aún no ha alcanzado al hacer scroll, acelerando la carga del sitio. ¡Ojo! No se debe usar en imágenes principales que esten arriba en nuestra página, ya que si no tendría el efecto contrario (retrasaría la carga de la web).

    A continuación, vemos una ejemplo de algunas de las propiedades comentadas más arriba:

    <img 
  src="imagen-800.jpg" 
  srcset="imagen-400.jpg 400w, 
          imagen-800.jpg 800w, 
          imagen-1200.jpg 1200w" 
  sizes="(max-width: 600px) 100vw, 
         (max-width: 1200px) 50vw, 
         800px" 
  width="1200" 
  height="800" 
  loading="lazy" 
  alt="Descripción de la imagen"
>

    EXPLICACIÓN:
    Con src indicamos la imagen de respaldo o fallback, para navegadores que no soporten el srcset.
    Luego con srcset indicamos que archivos existen y el ancho real de cada uno en píxeles.
    Con sizes indicamos el espacio que queremos que ocupe la imagen según el ancho del viewport. En este caso, en pantallas hasta 600px ocupará el ancho completo; en pantallas hasta 1200px, ocupará la mitad; y en pantallas más grandes, ocupará 800px fijos.
    Por último, aplicamos el loading="lazy" para que la imagen no se renderize hasta que el usuario llegue realmente con el scroll hasta ella.

    TEXTO RESPONSIVO

    El tamaño del texto debe adaptarse para mantener una lectura cómoda. Se recomienda mantener una longitud de línea entre 45 y 75 caracteres.

    Funciones matemáticas fluidas: clamp()
    La función clamp() permite que el texto escale suavemente según el tamaño de la pantalla (viewport) sin necesidad de utilizar @media queries. la forma de usarla es propiedad: clamp(valor_mínimo, valor_preferido, valor_máximo);. Algunos ejemplos pueden ser:

    h1 {
  font-size: clamp(1.5rem, 2.5vw + 1rem, 3rem);
}

p {
  width: clamp(45ch, 50%, 75ch);
}

    EXPLICACIÓN:
    Si nos fijamos en el ejemplo del parrafo, se establece el ancho en el 50% de forma predeterminada. Si el 50% es menor que 45ch, se usa 45ch como ancho; y si el 50% es más ancho que 75ch, se usa 75ch.

    Unidades de medida dinámicas:

    Tenemos unidades relativas al viewport (vw, vh, dvw, dvh), que basan el tamaño en las dimensiones de la ventana.

    • vw: $1\%$ de la anchura del viewport.
    • vh: $1\%$ de la altura del viewport.
    • vmin: $1\%$ de la dimensión más pequeña del viewport (ancho o alto).
    • vmax: $1\%$ de la dimensión más grande del viewport (ancho o alto).

    En cuando a dvh y dvw, representan lo mismo que vh y vw, pero de forma dinámica. Es decir, tienen en cuenta cuando el usuario hace scroll y los navegadores ocultan y muestran la barra del navegador (dispositivos móviles).

    Tambien unidades relativas al contenedor (Container Query Units) como cqw, que permite que el texto responda al tamaño del contenedor padre y no solo de la pantalla completa.

    Unidades relativas a la raíz (rem): Mantienen la accesibilidad respetando la configuración tipográfica por defecto del usuario o del navegador.

    Combinación de las anteriores: podemos mezclar rem con vw en un clamp(), por ejemplo: clamp(1rem, 0.8rem + 1vw, 2rem; para garantizar que el texto escale fluidamente pero siga siendo ampliable cuando el usuario hace zoom por accesibilidad.

    Container Queries para Tipografía (@container):

    Permiten aplicar cambios de tamaño de texto en función del espacio disponible en el contenedor padre, en lugar del tamaño de la pantalla global. Un ejemplo sería:

    @container card-container (min-width: 400px) {
  .card {
    flex-direction: row;
    align-items: center;
  }

  .card-img {
    width: 150px;
    height: 150px;
    object-fit: cover;
  }
}

    Propiedades de ajuste y equilibrio de texto:

    • text-wrap: balance: Equilibra automáticamente la cantidad de caracteres por línea en títulos y encabezados, evitando palabras sueltas (viudas) sin usar saltos de línea manuales.
    • text-wrap: pretty: Optimizado para párrafos extensos; evita la última palabra huérfana al final de un bloque de texto.
    • ch (Unidad de caracteres): Utilizada en max-width para controlar la longitud ideal de lectura (entre 45 y 75 caracteres por línea). Por ejemplo:
    p {
  max-width: 65ch; /* Excelente legibilidad responsiva */
}

    Fuentes Variables (Variable Fonts):

    Permiten ajustar dinámicamente el grosor (font-weight), inclinación o ancho de la letra mediante CSS según el ancho de la pantalla, cargando un único archivo ligero. Por ejemplo:

    h1 {
  /* Aumenta el grosor de la letra dinámicamente según el ancho del viewport */
  font-weight: clamp(400, 10vw * 100, 900);
}
