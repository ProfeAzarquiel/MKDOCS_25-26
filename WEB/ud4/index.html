    ¿QUE ES UN FRAMEWORK?

    Un framework CSS es una colección de archivos, estilos predefinidos, componentes de interfaz (botones, formularios, menús) y sistemas de rejilla (grids) listos para usar.

    En lugar de escribir todo el diseño desde cero con CSS tradicional, el desarrollador utiliza esta base estructurada para acelerar la maquetación y mantener la coherencia visual.

    Existen dos enfoques principales según cómo funcionan:

    Basado en componentes (Tradicionales): Proveen diseños visuales completos de los diferentes componentes que podemos encontrar en una web, como botones, barra de navegación, menu lateral, etc. Estos diseños se aplican usando clases predefinidas por el framework. Algunos ejemplos de este tipo, son Bootstrap, Bulma o Materialize.

    Basado en utilidades (Utility-first): en lugar de ofrecer componentes prediseñados como en el caso anterior, este proporciona multitud de pequeñas clases CSS centradas en una propiedad (como cambiar el color, ajustar el margen o configurar un flexbox). El ejemplo más popular de este tipo es Tailwind.

    BOOTSTRAP

    Bootstrap es el framework de interfaz web más consolidado de la industria, diseñado para construir rápidamente sitios y aplicaciones responsivas orientadas a componentes. A diferencia de los enfoques atómicos orientados a utilidades, Bootstrap te entrega una caja de herramientas lista para usar con componentes visuales completos (botones, modales, barras de navegación, formularios) y un sistema de maquetación probado para llevar un proyecto a producción en tiempo récord.

    Es la solución ideal cuando prima la velocidad de entrega, cuando buscas consistencia visual inmediata o cuando trabajas en equipos donde los desarrolladores necesitan maquetar interfaces atractivas y funcionales sin invertir horas ajustando CSS desde cero.

    PRINCIPALES CARACTERÍSTICAS

    • Prototipado ultrarrápido por componentes: Permite armar interfaces complejas en minutos uniendo piezas HTML preestilizadas (tarjetas, alertas, menús desplegables, tablas).
    • Sistema de Rejilla de 12 columnas: Ofrece una estructura de maquetación predecible basada en Flexbox con 6 breakpoints responsivos (xs a xxl) para organizar pantallas sin escribir CSS personalizado.
    • Interactividad y accesibilidad integrada: Sus componentes dinámicos (ventanas modales, tooltips, dropdowns) vienen listos en JavaScript modular (ESM con Floating UI) y cumplen por defecto con los estándares de accesibilidad ARIA.
    • Personalización dinámica por CSS Variables (Tokens): Su arquitectura (v5/v6) se apoya en variables CSS nativas (--bs-*), permitiendo alterar colores, márgenes o activar el modo oscuro en tiempo real sin necesidad de recompilar la librería.
    • Base uniforme gracias a Reboot: Normaliza las inconsistencias entre navegadores desde la raíz, garantizando que los elementos HTML estándar se comporten de forma idéntica en cualquier dispositivo.
    • Curva de aprendizaje muy suave: Cualquier perfil con conocimientos básicos de HTML puede maquetar interfaces funcionales casi desde el primer momento.

    INCONVENIENTES:

    • Diseños poco diferenciados: Las páginas pueden acabar teniendo una apariencia muy reconocible o genérica ("estilo Bootstrap") si no se aplica una capa profunda de personalización visual.

    • Sobrecarga de código si no se modulariza: Al incluir estilos e interactividad predefinidos para múltiples componentes, el archivo CSS/JS base puede resultar más pesado, a menos que se importen únicamente los módulos requeridos vía Sass y JS modular.

    • Fricción al salirse del estándar: Adaptar un componente de Bootstrap a un diseño de UI muy exclusivo o poco convencional puede obligarte a luchar contra la especificidad del framework y sobreescribir bastante código CSS personalizado.

    INSTALACIÓN Y USO DE BOOTSTRAP

    Para integrar Bootstrap en un proyecto existen dos métodos principales: a través de enlaces CDN (ideal para prototipado rápido o páginas HTML estáticas) o mediante el gestor de paquetes NPM (para proyectos modernos que utilicen empaquetadores como Vite, Webpack o Parcel).

    USO MEDIANTE CDN

    Puedes enlazar directamente los archivos CSS y JS precompilados alojados en los servidores de jsDelivr.

    Novedad clave en Bootstrap 6.0+: El código JavaScript de Bootstrap ha pasado a ser exclusivamente ESM (ES Modules), eliminado las compilaciones UMD globales. Por este motivo, las etiquetas <script> deben incluir obligatoriamente el atributo type="module". La versión bundle (bootstrap.bundle.min.js) ya integra las dependencias de posicionamiento interno (Floating UI).

    • En el <head> de la página (Estilos CSS):

      <link href="https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/css/bootstrap.min.css" rel="stylesheet" crossorigin="anonymous">

    • Al final del <body> (JavaScript Bundle con soporte ESM):

      <script type="module" src="https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/js/bootstrap.bundle.min.js" crossorigin="anonymous"></script>

    Si necesitas manipular la API de JavaScript mediante código personalizado, puedes hacer importaciones explícitas de módulos directamente desde el CDN:

        <script type="module">
        import { Tooltip } from 'https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/js/bootstrap.bundle.min.js';

        // Inicialización explicativa de un Tooltip
        const tooltipTriggerList = document.querySelectorAll('[data-bs-toggle="tooltip"]');
        const tooltipList = [...tooltipTriggerList].map(el => new Tooltip(el));
    </script>

    INSTALACIÓN Y CONFIGURACIÓN MEDIANTE NPM

    Para entornos de desarrollo basados en Node.js y herramientas de empaquetado (bundlers) como Vite, Webpack o Parcel, la instalación por NPM permite optimizar el peso del proyecto mediante tree-shaking y personalizar temas con Sass.

    • Paso 1: Instalación del paquete base

      Ejecuta el siguiente comando en la terminal de tu proyecto:

      npm install bootstrap@6.0.0-alpha.1

      (Opcional: Si planeas usar menús flotantes, tooltips o popovers en builds personalizadas sin el bundle precompilado, incluye su peer-dependency Floating UI):

      npm install bootstrap @floating-ui/dom

    • Paso 2: Importación de estilos y JavaScript

      • Opción A: Importación directa en el punto de entrada JS (main.js / index.js)

        // Importar los estilos CSS completos precompilados
import 'bootstrap/dist/css/bootstrap.min.css';

// Importar los componentes JS de forma modular (Tree-Shaking habilitado)
import { Modal, Tooltip } from 'bootstrap';

      • Opción B: Importación con Sass modular (styles.scss)

      En Bootstrap 6 se adoptó el estándar de módulos Sass (@use / @forward), sustituyendo la directiva obsoleta @import:

          // Importar todo el framework mediante el sistema de módulos de Sass
    @use "bootstrap/scss/bootstrap";

    // (Opcional) Personalizar variables o tokens globales mediante la función with()
    @use "bootstrap/scss/bootstrap" with (
        $root-tokens: (
            --border-radius: 0.375rem,
            --spacer: 1.5rem,
        )
    );

    CONTENEDORES BOOTSTRAP

    Bootstrap ofrece varios tipos de contenedores para adaptar el contenido según el ancho del navegador:

    • container: establece un max-width fijo en cada breakpoint responsivo, dejando márgenes proporcionales centrados a izquierda y derecha.
    • container-fluid: ocupa el 100% del ancho de la pantalla (width: 100%) en todos los breakpoints.
    • container-{breakpoint}: (ej. container-md) es 100% ancho hasta alcanzar el breakpoint especificado, a partir del cual se comporta como un contenedor fijo.
      <body>
    <div class="container">
    </div>

    <div class="container-fluid">
    </div>
</body>

    GRID BOOTSTRAP

    El sistema de rejilla (Grid) de Bootstrap se basa en Flexbox y es completamente responsivo.

    FILAS

    La estructura general para definir esquemas mediante Bootstrap consiste en una rejilla (grid) compuesta por filas (.row), y dentro de cada fila se pueden definir hasta 12 columnas.

    <body>
    <div class="container">
        <div class="row"></div>
        <div class="row"></div>
    </div>
</body>

    COLUMNAS

    A la hora de definir columnas, podemos indicar el ancho específico que van a ocupar o permitir que tengan un ancho automático.

    Para indicar un ancho fijo existen las clases desde col-1 hasta col-12, las cuales crean una columna cuyo ancho abarca el número especificado de unidades sobre 12. Por ejemplo, para crear una columna que ocupe la mitad de la fila, usaremos col-6.

    <body>
    <div class="container">
        <div class="row">
            <div class="col-6"></div>
            <div class="col-3"></div>
            <div class="col-3"></div>
        </div>
    </div>
</body>

    Por otro lado, para definir columnas de ancho automático existe la clase col. El ancho de estas columnas se calculará distribuyendo a partes iguales el espacio disponible entre el número de columnas presentes en esa fila.

    <body>
    <div class="container">
        <div class="row">
            <div class="col"></div>
            <div class="col"></div>
            <div class="col"></div>
        </div>
    </div>
</body>

    Además, las columnas incluyen de forma predeterminada un espacio de separación horizontal (GUTTER), personalizable mediante la familia de utilidades g-*, gx-* o gy-* (por ejemplo, g-0 para eliminar márgenes internos).

    BREAKPOINTS BOOTSTRAP

    Un breakpoint es un punto de corte basado en el ancho de la pantalla (en píxeles) donde se produce un cambio en la disposición del diseño web.

    Las versiones actuales de Bootstrap (v5.3 / v6.0) incluyen 6 breakpoints predefinidos (incorporando la categoría xxl para pantallas ultra anchas):

    • xs (Extra small): Entre 0 y 576px : col-1...col-12
    • sm (Small): Entre 576px y 768px : col-sm-1...col-sm-12
    • md (Medium): Entre 768px y 992px : col-md-1...col-md-12
    • lg (Large): Entre 992px y 1200px : col-lg-1...col-lg-12
    • xl (Extra large): Entre 1200px y 1400px : col-xl-1...col-xl-12
    • xxl (Extra extra large): A partir de 1400px : col-xxl-1...col-xxl-12

    Nota de versión: En las especificaciones más recientes de Bootstrap 6.0, las clases de utilidad responsiva también adoptan la convención de prefijo tipo md:col-6 o lg:d-none, manteniendo compatibilidad completa con el sistema de 12 columnas.

    Ejemplo de rejilla adaptable según el dispositivo:

    <body>
    <div class="container">
        <div class="row">
            <div class="col-12 col-sm-6 col-md-4 col-lg-2"></div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-2"></div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-2"></div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-2"></div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-2"></div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-2"></div>
        </div>
    </div>
</body>

    Esta opción también es compatible con la definición de columnas de ancho automático añadiendo la escala correspondiente, por ejemplo, col-md.

    Por otro lado, es posible forzar un salto de línea dentro de una fila mediante la clase de utilidad w-100:

    <div class="row">
    <div class="col"></div>
    <div class="col"></div>
    <div class="w-100"></div>   <!--Salto de línea-->
    <div class="col"></div>
</div>

    PERSONALIZACIÓN DE COLUMNAS

    Dentro de la definición de columnas en las filas de la rejilla, existen varios parámetros para personalizar su posicionamiento:

    DESPLAZAMIENTO

    Podemos desplazar columnas hacia la derecha utilizando las clases offset-* o sus variantes responsivas (offset-md-*). Esto añade un margen izquierdo equivalente al número de columnas indicado.

    <div class="container">
    <div class="row">
        <div class="col-md-4">Columna 1</div>
        <div class="col-md-4 offset-md-4">Columna 2 desplazada 4 espacios a la derecha</div>
    </div>
</div>

    ALINEAMIENTO

    Al estar basado en Flexbox, Bootstrap permite alinear columnas tanto vertical como horizontalmente:

    • Vertical: Mediante clases en la fila como align-items-start, align-items-center o align-items-end, o individualmente en una columna específica con align-self-start, align-self-center, align-self-end.

    • Horizontal: Mediante clases en la fila como justify-content-start, justify-content-center, justify-content-end, justify-content-between, justify-content-around o justify-content-evenly.

      Columna 1
      Columna 2
      Columna centrada al medio

    ORDENACIÓN

    Podemos cambiar el orden visual de las columnas sin modificar la estructura del código HTML usando las clases order-* (order-1 a order-5, además de order-first y order-last).

    <div class="container">
    <div class="row">
        <div class="col order-last">Primera en HTML, se muestra la última</div>
        <div class="col">Segunda en HTML</div>
        <div class="col order-first">Última en HTML, se muestra la primera</div>
    </div>
</div>

    MÁRGENES

    Se pueden usar márgenes automáticos de Flexbox como ms-auto (margin-start, margen izquierdo automático) o me-auto (margin-end, margen derecho automático) para empujar elementos dentro de la fila.

    <div class="container">
    <div class="row">
        <div class="col-md-4">Columna a la izquierda</div>
        <div class="col-md-4 ms-auto">Columna empujada a la derecha</div>
    </div>
</div>

    CONTENIDO

    En este apartado se muestran los ejemplos para insertar contenidos comunes. Para ampliar la información, consultar la documentación oficial.

    TEXTOS

    Bootstrap incluye utilidades para modificar el tamaño, peso, alineación y estilo del texto (.lead, encabecados .display-1 a .display-6, alineación text-start, text-center, text-end, estilos fw-bold, fst-italic, text-uppercase y tonos como text-body-secondary).

    <p class="lead">Este es un párrafo destacado que llama la atención del usuario.</p>
<p class="text-center fw-bold text-uppercase">Texto centrado, en negrita y en mayúsculas.</p>
<p class="text-body-secondary">Texto secundario con tono atenuado.</p>

    IMÁGENES

    Las imágenes responsivas emplean la clase img-fluid (max-width: 100% y height: auto). También se pueden aplicar bordes redondeados (rounded) o formato miniatura (img-thumbnail).

    <!-- Imagen adaptativa con bordes redondeados -->
<img src="imagen.jpg" class="img-fluid rounded" alt="Imagen adaptativa">

<!-- Imagen estilo miniatura -->
<img src="avatar.jpg" class="img-thumbnail" alt="Avatar miniatura">

    FIGURAS

    Para mostrar imágenes acompañadas de un pie explicativo mediante etiquetas semánticas HTML5 <figure> y <figcaption>:

    <figure class="figure">
    <img src="paisaje.jpg" class="figure-img img-fluid rounded" alt="Descripción de la imagen">
    <figcaption class="figure-caption text-end">Pie de foto explicativo alineado a la derecha.</figcaption>
</figure>

    FORMULARIOS

    Bootstrap ofrece componentes de formulario preestilizados. Puedes revisar las pautas detalladas en la documentación oficial.

    FORM CONTROL

    Aplica estilos a entradas de texto, números, emails, fechas y selectores de color.

    • form-control: clase principal para elementos <input> y <textarea>.
    • form-label: aplica margen y formato a <label>.
    • form-control-color: ajusta el tamaño para <input type="color">.
    • col-form-label: alinea etiquetas verticalmente en formularios horizontales.
    • visually-hidden: oculta un elemento de la vista gráfica sin perder accesibilidad.
      <div class="mb-3">
    <label for="emailInput" class="form-label">Correo Electrónico</label>
    <input type="email" class="form-control" id="emailInput" placeholder="nombre@ejemplo.com">
</div>

<!-- Ejemplo de selector de color con alineación horizontal -->
<div class="mb-3 row">
    <label for="colorPicker" class="col-sm-2 col-form-label">Color de perfil</label>
    <div class="col-sm-10">
        <input type="color" class="form-control form-control-color" id="colorPicker" value="#563d7c">
    </div>
</div>

<!-- Campo con etiqueta accesible exclusivamente para lectores de pantalla -->
<label for="campoOculto" class="visually-hidden">Búsqueda rápida</label>
<input type="text" class="form-control" id="campoOculto" placeholder="Buscar...">

    SELECTS

    • form-select: reemplaza el estilo nativo de los elementos <select>.
      <div class="mb-3">
    <label for="opcionesSelect" class="form-label">Selecciona una opción</label>
    <select class="form-select" id="opcionesSelect">
        <option selected>Abre este menú desplegable</option>
        <option value="1">Opción 1</option>
        <option value="2">Opción 2</option>
        <option value="3">Opción 3</option>
    </select>
</div>

    CHECKS & RADIOS

    • form-check: contenedor para el control y su etiqueta.
    • form-check-input: estilos para <input type="checkbox"> o <input type="radio">.
    • form-check-label: estilos para <label>.
    • form-switch: convierte el checkbox en un interruptor deslizable al agregarse a form-check.
    • form-check-inline: dispone los campos de forma horizontal.
    • form-check-reverse: coloca la etiqueta a la izquierda y la casilla a la derecha.
      <!-- Checkbox estándar -->
<div class="form-check">
    <input class="form-check-input" type="checkbox" id="checkStandard">
    <label class="form-check-label" for="checkStandard">Acepto los términos</label>
</div>

<!-- Switch -->
<div class="form-check form-switch">
    <input class="form-check-input" type="checkbox" role="switch" id="switchNotification">
    <label class="form-check-label" for="switchNotification">Activar notificaciones</label>
</div>

<!-- Inline Checkboxes -->
<div class="form-check form-check-inline">
    <input class="form-check-input" type="checkbox" id="inlineCheck1" value="opcion1">
    <label class="form-check-label" for="inlineCheck1">Opción 1</label>
</div>

<!-- Checkbox Reverso -->
<div class="form-check form-check-reverse">
    <input class="form-check-input" type="checkbox" id="reverseCheck">
    <label class="form-check-label" for="reverseCheck">Etiqueta a la izquierda</label>
</div>

    RANGE

    • form-range: diseño estilizado para controles <input type="range">.
      <div class="mb-3">
    <label for="customRange" class="form-label">Selecciona un nivel</label>
    <input type="range" class="form-range" min="0" max="5" step="0.5" id="customRange">
</div>

    VALIDATION

    Manejo de respuestas de validación visual de formularios:

    • needs-validation: inhabilita la validación por defecto del navegador en el <form>.
    • was-validated: clase aplicada tras intentar enviar el formulario para mostrar los estados.
    • is-invalid / is-valid: fuerzan visualmente el estado de error o éxito.
    • invalid-feedback / valid-feedback: contenedores para mensajes explicativos.
    • invalid-tooltip / valid-tooltip: muestran los mensajes flotantes en forma de bocadillo.
      <form class="needs-validation was-validated" novalidate>
    <div class="mb-3">
        <label for="validarUsuario" class="form-label">Nombre de usuario</label>
        <input type="text" class="form-control is-invalid" id="validarUsuario" required>
        <div class="invalid-feedback">Por favor, elige un nombre de usuario válido.</div>
    </div>
    <div class="mb-3">
        <label for="validarEmail" class="form-label">Email</label>
        <input type="email" class="form-control is-valid" id="validarEmail" value="correo@valido.com" required>
        <div class="valid-feedback">¡El email introducido es correcto!</div>
    </div>
</form>

    COMPONENTES

    Ejemplos de componentes interactivos de interfaz. Consulta más detalles en la documentación oficial.

    BOTONES

    Utilizan la clase base .btn combinada con variantes de color (btn-primary, btn-secondary, btn-success), bordes transparentes (btn-outline-*) o tamaños (btn-lg, btn-sm).

    <!-- Botones estándar -->
<button type="button" class="btn btn-primary">Primario</button>
<button type="button" class="btn btn-secondary">Secundario</button>

<!-- Botón delineado y tamaño grande -->
<button type="button" class="btn btn-outline-success">Guardar</button>
<button type="button" class="btn btn-danger btn-lg">Eliminar</button>

    TARJETAS

    Contenedores flexibles (card) para agrupar imagen, cabecera, contenido y acciones.

    <div class="card" style="width: 18rem;">
    <img src="portada.jpg" class="card-img-top" alt="Imagen de portada">
    <div class="card-body">
        <h5 class="card-title">Título de la Tarjeta</h5>
        <p class="card-text">Texto descriptivo breve contenido dentro de la tarjeta.</p>
        <a href="#" class="btn btn-primary">Saber más</a>
    </div>
    <div class="card-footer text-muted">Hace 2 días</div>
</div>

    MODALES

    Ventanas emergentes interactivas. En las versiones actuales de Bootstrap (v5 / v6), los atributos Data JavaScript llevan el espacio de nombres data-bs-* (data-bs-toggle y data-bs-target).

    <!-- Botón activador del modal -->
<button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#miModal">
    Abrir ventana modal
</button>

<!-- Estructura HTML del Modal -->
<div class="modal fade" id="miModal" tabindex="-1" aria-labelledby="miModalTitulo" aria-hidden="true">
    <div class="modal-dialog">
        <div class="modal-content">
            <div class="modal-header">
                <h5 class="modal-title" id="miModalTitulo">Título del Modal</h5>
                <button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Cerrar"></button>
            </div>
            <div class="modal-body">
                Contenido principal explicativo dentro de la ventana modal.
            </div>
            <div class="modal-footer">
                <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Cancelar</button>
                <button type="button" class="btn btn-primary">Confirmar</button>
            </div>
        </div>
    </div>
</div>

    NAVBAR

    Barra de navegación responsiva. Al igual que el resto de componentes interactivos, emplea data-bs-toggle="collapse" y data-bs-target="#menuNavegacion".

    <nav class="navbar navbar-expand-lg navbar-light bg-light">
    <div class="container-fluid">
        <a class="navbar-brand" href="#">MiProyecto</a>
        <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#menuNavegacion" aria-controls="menuNavegacion" aria-expanded="false" aria-label="Toggle navigation">
            <span class="navbar-toggler-icon"></span>
        </button>
        <div class="collapse navbar-collapse" id="menuNavegacion">

    TAILWIND

    Como ya hemos mencionado, Tailwind CSS es un framework de CSS de código abierto enfocado a utilizades (utility-first). A diferencia de otros frameworks tradicionales (como Bootstrap), no ofrece componentes HTML ya preestilizadas (div, btn, row, column...). En su lugar, proporciona pequeñas clases de propósito único, que definen un estilo CSS concreto y que aplicamos directamente en nuestro fichero HTML para construir diseños desde cero.

    PRINCIPALES CARACTERÍSTICAS:

    • Enfoque Utility-First: Cada clase controla una propiedad CSS específica (márgenes, colores, tipografía, flexbox), lo que permite diseñar interfaces únicas sin salir del código HTML.
    • Sin componentes pre-diseñados: No te impone una estética fija; te da los bloques básicos para que crees tu propio sistema visual (Design System).
    • Diseño responsivo sencillo (Mobile-first): Incorpora prefijos de tamaño de pantalla (como sm:, md:, lg:, xl:) para adaptar los estilos a distintos dispositivos de manera declarativa.
    • Estados interactivos y modo oscuro: Permite manejar estados del navegador (hover:, focus:, active:) y el modo oscuro (dark:) simplemente añadiendo prefijos a las clases.
    • Optimización y peso reducido en producción: Analiza tu código y elimina automáticamente todas las clases de CSS que no estás utilizando, lo que deja un archivo final muy ligero.
    • Altamente personalizable: Puedes configurar los colores, fuentes, espaciados y puntos de quiebre a través de su archivo de configuración o variables.
    • Integración con frameworks modernos: Funciona de forma fluida con herramientas y frameworks de frontend como React, Next.js, Vue, Astro o Laravel.

    INCONVENIENTES:

    • Puede acabar generando demasiado ruido (sobrecargado) en el HTML y que resulte complejo de leer

    • Mantener y depurar las clases utilizadas puede ser engorroso en ocasiones

    • Curva de aprendizaje larga al principio, para aquellos que vienen de CSS tradicional

    INSTALACIÓN/USO TAILWIND

    DESARROLLO

    Para usarlo en entornos de desarrollo, la forma más rápida de empezar a usar Tailwind es añadiendo su enlace CDN (Red de Entrega de Contenido) al <head> de nuestro HTML:

    <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>

    PRODUCCIÓN

    Sin embargo, esta opción no es válida para entornos de producción. Para estos casos, la forma más sencilla y rápida de empezar a usar Tailwind es con la herramienta CLI de Tailwind. Podemos instalarla mediante el gestor de paquetes de Node.js con el comando:

    npm install tailwindcss @tailwindcss/cli

    Luego importaremos Tailwind en nuestro fichero CSS principal (en este ejemplo llamado input.css):

    @import "tailwindcss";

    Arrancamos el proceso de compilación con la opción de que se mantenga a la escucha de cambios. Lo cual va a ir generando un CSS reducido en base a las clases que estemos usando (en este ejemplo llamado output.css):

    npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch

    Por útlimo, enlazamos el CSS compilado en el <head> de nuestro HTML y podemos comenzar a dar estilos con las clases Tailwind:

    <link href="./output.css" rel="stylesheet">

    Opción sin Node.js

    La CLI de Tailwind también está disponible como ejecutable independiente si queremos usarla sin instalar Node.js.

    Luego abrimos VSCode e instalamos (si no lo tenemos instalado ya) el plugin oficial de Tailwind, llamado Tailwind CSS IntelliSense, desarrollado por "Tailwind Labs":

    Suponiendo que acabamos de abrir una nueva ventana de VSCode, donde no tenemos ningún proyecto, ni archivo activo; hacemos click en Archivo -> Guardar Workspace como...

    Nombramos el Workspace de forma que identifique inequivocamente el proyecto actual (por ejemplo, nombre comercial del cliente y tipo de producto desarrollado: "appweb-technolab") y lo guardaremos en la raíz de la carpeta donde ubicaremos nuestro proyecto.

    CLASES MÁS COMUNES POR CATEGORÍA

    En la documentación oficial de TailwindCSS, podemos encontrar todas las posibles clases de configuración que ofrece este framework. No obstante, a continuación vamos a hacer un repaso por algunas de las más utilizadas:

    LAYOUT AND SPACING

    Controla la disposición de los elementos en el flujo de la página, su visibilidad, posicionamiento y los espacios internos y externos.

    • Clases Principales:

    • Display: block, inline-block, inline, flex, grid, hidden (aplica display: none).

    • Positioning: static, relative, absolute, fixed, sticky.
    • Top / Right / Bottom / Left: top-0, right-4, bottom-2, left-1/2, -top-2 (valores negativos).
    • Z-Index: z-0, z-10, z-20, z-50, z-auto.
    • Padding (Espaciado Interno):
    • Todos los lados: p-2 (8px), p-4 (16px), p-8 (32px).
    • Ejes: px-4 (horizontal), py-2 (vertical).
    • Lados individuales: pt-4 (top), pr-4 (right), pb-4 (bottom), pl-4 (left).
    • Margin (Espaciado Externo):
    • Similar a padding: m-4, mx-auto (centrado horizontal), my-6, mt-2, -mt-4 (margen negativo).
    • Space Between (Separación de hijos): space-x-4 (margen horizontal entre elementos hijos), space-y-2.
    Ejemplo de uso
    <!-- Card con posición relativa, espaciado interno y margen horizontal centrado -->
<div class="relative max-w-sm mx-auto p-6 bg-white shadow-md rounded-lg space-y-4">
  <span class="absolute top-2 right-2 z-10 px-2 py-1 text-xs bg-red-500 text-white rounded">
    Nuevo
  </span>
  <h2 class="pt-2">Título de la Tarjeta</h2>
</div>

    SIZING

    Define el ancho (width) y alto (height) de los elementos, así como sus restricciones mínimas y máximas.

    • Clases Principales:

    • Width (Ancho):

    • Fijos: w-4 (16px), w-16 (64px), w-64 (256px).
    • Porcentajes / Fracciones: w-1/2 (50%), w-1/3 (33.33%), w-full (100%).
    • Pantalla / Auto: w-screen (100vw), w-auto.
    • Height (Alto):
    • Fijos: h-8, h-16, h-64.
    • Absolutos / Pantalla: h-full, h-screen (100vh), h-auto.
    • Min / Max Width:
    • min-w-0, min-w-full.
    • max-w-xs, max-w-md, max-w-xl, max-w-7xl, max-w-full.
    • Min / Max Height:
    • min-h-screen (muy usado en layouts principales), max-h-64, max-h-full.
    Ejemplo de uso
    <!-- Contenedor que ocupa al menos todo el alto de pantalla y ancho ajustado -->
<main class="min-h-screen w-full max-w-4xl mx-auto h-auto">
  <div class="w-full h-32 bg-blue-100">
    Encabezado de altura fija
  </div>
</main>

    COLORS

    Tailwind utiliza una paleta de colores integrada con intensidades que van de 50 (más claro) a 950 (más oscuro).

    • Clases Principales:

    • Color de Texto: text-slate-800, text-blue-600, text-white, text-transparent.

    • Color de Fondo: bg-white, bg-gray-100, bg-indigo-500, bg-emerald-700.
    • Opacidad: opacity-50, opacity-75 (aplica a todo el elemento) o modifiers de color como bg-black/50, text-blue-500/80.
    • Gradientes:
    • Dirección: bg-gradient-to-r (derecha), bg-gradient-to-b (abajo), bg-gradient-to-tr (arriba-derecha).
    • Colores: from-indigo-500, via-purple-500, to-pink-500.
    Ejemplo de uso
    <!-- Botón con fondo degradado y texto blanco con transparencia al pasar el cursor -->
<button class="px-5 py-2.5 bg-gradient-to-r from-cyan-500 to-blue-500 text-white font-medium rounded-lg hover:opacity-90">
  Guardar Cambios
</button>

    TIPOGRAPHY

    Permite gestionar familias tipográficas, tamaños, pesos, alineación, interlineado y formato de texto.

    • Clases Principales:

    • Font Family: font-sans, font-serif, font-mono.

    • Font Size: text-xs, text-sm, text-base (16px), text-lg, text-xl, text-2xl, text-4xl, text-6xl.
    • Font Weight (Grosor): font-light, font-normal, font-medium, font-semibold, font-bold.
    • Text Align: text-left, text-center, text-right, text-justify.
    • Line Height (Interlineado): leading-none, leading-tight, leading-normal, leading-relaxed, leading-loose.
    • Letter Spacing: tracking-tighter, tracking-normal, tracking-wide, tracking-widest.
    • Transform / Style: uppercase, lowercase, capitalize, italic, underline, line-through.
    Ejemplo de uso
    <article class="font-sans">
  <h1 class="text-3xl font-bold tracking-tight text-gray-900 uppercase">
    Título Principal
  </h1>
  <p class="text-base font-normal leading-relaxed text-gray-600">
    Este es un párrafo con un interlineado cómodo para la lectura y texto estilizado.
  </p>
</article>

    BORDERS

    Define el grosor, color, estilo y curvatura de los bordes, además de divisores automáticos entre elementos.

    • Clases Principales:

    • Border Width: border (1px), border-0, border-2, border-4, border-t-2 (solo borde superior).

    • Border Color: border-gray-200, border-blue-500, border-transparent.
    • Border Radius (Esquinas redondeadas):
    • rounded-none, rounded-sm, rounded (4px), rounded-md, rounded-lg, rounded-xl, rounded-full (píldora / círculo).
    • Border Style: border-solid, border-dashed, border-dotted.
    • Divide Utilities: divide-y, divide-x, divide-gray-200 (añade bordes automáticos entre elementos lista/contenedor).
    Ejemplo de uso
    <!-- Input con borde y lista con divisores automáticos -->
<input class="border border-gray-300 rounded-md p-2 focus:border-indigo-500" type="text" />

<ul class="divide-y divide-gray-200 border border-gray-200 rounded-lg mt-4">
  <li class="p-3">Elemento 1</li>
  <li class="p-3">Elemento 2</li>
</ul>

    FLEXBOX Y GRID

    Herramientas principales para crear distribuciones y layouts complejos de forma declarativa.

    FlexBox
    • Contenedor Flex: flex, inline-flex.
    • Dirección: flex-row, flex-row-reverse, flex-col, flex-col-reverse.
    • Alineación Vertical (Cross Axis): items-start, items-center, items-end, items-baseline, items-stretch.
    • Alineación Horizontal (Main Axis): justify-start, justify-center, justify-end, justify-between, justify-around, justify-evenly.
    • Gap (Espaciado): gap-2, gap-4, gap-x-6.
    • Comportamiento de Hijos: flex-1 (crece/encoge libremente), flex-shrink-0 (no se encoge), flex-grow.
    Grid
    • Contenedor Grid: grid, inline-grid.
    • Columnas: grid-cols-1, grid-cols-2, grid-cols-3, grid-cols-12.
    • Filas: grid-rows-1, grid-rows-4.
    • Ocupación de Espacio (Spanning): col-span-2, col-span-full, row-span-2.
    • Gap: gap-4, gap-x-4, gap-y-8.
    Ejemplo de uso
    <!-- Navbar con Flexbox -->
<nav class="flex items-center justify-between p-4 bg-gray-800 text-white">
  <div class="font-bold text-xl">Logo</div>
  <div class="flex gap-4">
    <a href="#">Inicio</a>
    <a href="#">Servicios</a>
  </div>
</nav>

<!-- Dashboard con Grid -->
<div class="grid grid-cols-1 md:grid-cols-3 gap-6 my-6">
  <div class="col-span-2 bg-gray-100 p-4">Panel Principal (2 cols)</div>
  <div class="col-span-1 bg-gray-200 p-4">Lateral (1 col)</div>
</div>

    DISEÑO RESPONSIVE CON TAILWIND

    Tailwind utiliza un enfoque Mobile First. Las clases sin prefijo se aplican a todos los tamaños de pantalla, mientras que los prefijos modifiadores aplican a partir del breakpoint indicado en adelante.

    Breakpoints Predeterminados
    Prefijo Ancho Mínimo Pantalla Típica
    sm: 640px Teléfonos grandes / Tablets pequeñas
    md: 768px Tablets
    lg: 1024px Laptops / Desktops pequeñas
    xl: 1280px Monitores de escritorio
    2xl: 1536px Monitores grandes
    • Sintaxis:

    Para aplicar una regla responsive, coloca el prefijo seguido de dos puntos antes de cualquier clase de Tailwind:
    [breakpoint]:[clase] (ej: md:flex-row, lg:text-xl).

    Ejemplo de uso
    <!-- 
  - Móvil: 1 columna, texto centrado, fondo gris claro.
  - Tablet (md): 2 columnas, texto alineado a la izquierda.
  - Laptop (lg): 4 columnas, fondo blanco.
-->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4 p-4 text-center md:text-left bg-gray-50 lg:bg-white">
  <div class="p-4 border rounded">Tarjeta 1</div>
  <div class="p-4 border rounded">Tarjeta 2</div>
  <div class="p-4 border rounded">Tarjeta 3</div>
  <div class="p-4 border rounded">Tarjeta 4</div>
</div>
