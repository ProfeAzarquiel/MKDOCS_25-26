    DISEÑOS CON JAVASCRIPT

    DESCRIPCIÓN DEL ENTORNO

    Para realizar los ejercicios de este apartado, partiremos de una máquina donde previamente tenemos instalado Visual Studio Code y Node.js con el gestor de paquetes PNMP.

    La idea es crear un monorepositorio multipaquete, es decir, un único repositorio dentro del cual tendremos varios proyectos diferentes y podremos lanzar releases independientes para cada proyecto. Para esto será necesario usar Commits Semánticos, por ejemplo con Conventional Commits; y que, además de la carpeta ráiz, los directorios de cada proyecto tengan su propio package.json.

    En el package.json del directorio raíz, indicaremos que lo que haya en la carpeta donde crearemos nuestros projetos, lo tome como diferentes espacios de trabajo, agregando lo siguiente:

    "workspaces": [
    "projects/*"
],

    Y además, si queremos usar PNPM (como es nuestro caso), para que reconozca los diferentes workspaces, deberemos crear también en la raíz un archivo pnpm-workspace.yaml, que contendrá lo siguiente:

    packages:
- "projects/*"

    REACT + TAILWIND + VITE

    ¿QUE ES REACT?

    React es una librería Open Source de JavaScript que nos permite construir aplicaciones web modernas, dinámicas y escalables, de forma declarativa y basada en componentes.

    CARACTERÍSTICAS PRINCIPALES

    React se basa en la creación de componentes que pueden ser reutilizados en diferentes partes de la aplicación.

    Esto significa que las interfaces de usuario se dividen en “piezas” independientes y reutilizables, cada uno de los cuales gestionan su propio estado y lógica.

    Esto promueve la modularidad y facilita el mantenimiento del código.

    React utiliza JSX (JavaScript XML), una extensión de la sintaxis de JavaScript que permite escribir código HTML directamente en archivos JavaScript.

    Esto hace que el código sea más legible y fácil de escribir.

    React utiliza un DOM virtual para optimizar el rendimiento. El virtual DOM es una representacion interna del DOM del navegador.

    En lugar de actualizar el DOM real cada vez que hay un cambio, React actualiza su virtual del DOM y luego sincroniza solo las partes que han cambiado.

    Esto (en teoría, y casi siempre) reduce el costo computacional y mejora la velocidad de la aplicación.

    React sigue un flujo de datos unidireccional, lo que significa que los datos fluyen desde los componentes padres hacia los componentes hijos.

    Además, se apoya profundamente en el concepto de inmutabilidad de los objetos, como parte de su sistema de gestión interna (esto es ventaja o debilidad, según como lo quieras vender).

    Esto facilita la depuración y el seguimiento de los cambios en la aplicación.

    React utiliza un enfoque declarativo. Esto significa que tú simplmente describes cómo debe verse la interfaz en un estado dado.

    Por debajo, React se encarga de actualizar el DOM (Document Object Model) cuando ese estado cambia.

    Eso te facilita la vida como desarrollador, además de que elimina muchos errores y mejora la eficiencia.

    ¿QUE ES VITE?

    Vite una herramienta de construcción moderna para proyectos web que ofrece una experiencia de desarrollo extremadamente rápida.

    Vite tiene Hot Reload, es decir, que los cambios que hagas en el codigo se muestran instantáneamente en la “preview” de tu proyecto, lo que facilita mucho el desarrollo.

    ACLARACIÓN

    Anteriormente, para crear un proyecto se empleaba el comando create-react-app, pero ha quedado obsoleto. Ya no es la opción recomendada para crear proyectos en React.

    CREANDO NUESTRO PRIMER PROYECTO

    INICIALIZAR REPOSITORIO

    En primer lugar, accedemos a nuestra cuenta de GitHub y creamos un repositorio totalmente vacío, incluso sin README.md.

    Una vez que tenemos nuestro repositorio remoto, crearemos el directorio local que queremos sincronizar con dicho repositorio. Luego abrimos un terminal y nos posicionamos dentro de él para inicializar el repositorio Git y enlazarlo con GitHub. Esto lo podemos hacer con los siguientes comandos:

    A TENER EN CUENTA

    Si es tu primera interacción con GitHub desde VsCode, te pedirá que añadas tus credenciales de GitHub, a tu configuración de Git, con los comandos: 

    git config --global user.email "alumno.github@ies-azarquiel.es"
git config --global user.name "AlumnoGit"


    git init
git add .
git commit -m "Initial Commit"
git branch -M main
git remote add origin https://github.com/my-github-user/my-react-repo.git
git push -u origin main

    INICIALIZAR NODE

    Creamos el package.json en la raíz de nuestro repositorio con:

    pnpm init

    CREAR CARPETA DE PROYECTOS Y AÑADIR UNO NUEVO

    mkdir projects
cd projects
pnpm create vite

    Esto nos consultará una seríe de datos para crear nuestro proyecto, como el nombre o framework a utilizar, como vemos a continuación:

    Project name:
│  hello-world
│
◇  Select a framework:
│  React
│
◇  Select a variant:
│  JavaScript + React Compiler
│
◆  Install with pnpm and start now?
│  ● Yes / ○ No

    Al confirmar el último paso, realizará automáticamente los comandos pnpm install y pnpm vite, de modo que cuando finalice, tendremos accesible nuestro servidor de desarrollo.

    EJECUTAR SERVIDOR DE DESARROLLO

    Con el siguiente comando, levantamos nustro servidor de desarrollo en la dirección http://localhost:5173/ donde podemos ver la "preview" de nuestro proyecto.

    pnpm vite

    INSTALACIÓN DE TAILWIND

    A partir de la versión 4 de Tailwind CSS, es mucho más sencillo su integración con Vite. Deberemos realizar los siguintes pasos:

    INTALAR PLUGIN TAILWIND

    Instalamos Tailwind y su plugin oficial para Vite, usando:

    pnpm install tailwindcss @tailwindcss/vite

    CONFIGURAR EL FICHERO vite.config.js

    Importamos Tailwind y registramos su plugin en el array de plugins, agregando:

    import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
plugins: [
    tailwindcss(),
],
})

    CONFIGURAR EL FICHERO index.css

    Sustituiremos el contenido nuestro index.css, por la siguiente directiva simplificada para Tailwind V4:

    @import "tailwindcss";
